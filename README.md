Global Electronics Retail – Sales Analysis Dashboard

Project Overview

An interactive sales analysis dashboard built using Microsoft Power BI to analyze Global Electronics Retail business performance across countries, products, and customer demographics.

The project focuses on transforming sales data into meaningful business insights through data modeling, DAX measures, KPI cards, and interactive visualizations.

Business Objectives

* Analyze overall revenue and profit performance.
* Identify top-performing countries.
* Evaluate product revenue performance.
* Understand customer demographics by age group and gender.
* Enable interactive analysis using slicers.

Tools & Technologies

* Microsoft Power BI Desktop
* DAX (Data Analysis Expressions)
* Data Modeling & Relationships
* Interactive Data Visualization

## Key Performance Indicators (KPIs)

- **Total Revenue:** 55.76M
- **Total Profit:** 32.66M
- **Total Orders:** 26.326K
- **Total Quantity Sold:** 198K

Interactive Filters

The dashboard includes three interactive slicers:

* Country
* Product Category
* Order Date

These filters allow users to explore the data dynamically.

Data Quality Note

Records with missing country mappings were retained and categorized as UNMAPPED rather than excluded. This ensures that the dashboard’s revenue and profit totals include those records.
